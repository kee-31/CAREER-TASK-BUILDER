# Career Task Builder

A lightweight task dashboard for organizing career preparation across testing, data analytics, and internship goals.

## Features

- Track tasks by career category
- Set priority, due dates, notes, and reference links
- Filter tasks by status and priority
- Search across tasks
- View progress statistics and completion percentages
- Toggle between light and dark themes
- Persist tasks in browser local storage

## Run locally

Open `index.html` in a browser. No build tools or dependencies are required.

## Tech stack

- HTML
- CSS
- Vanilla JavaScript
